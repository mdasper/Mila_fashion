# Mila Fashions — Haute Couture & Bespoke Luxury E-Commerce Web Application

A bespoke haute couture luxury clothing e-commerce web application built for **Mila Fashions**, blending timeless Indian heritage handlooms (Kanchipuram mulberry silks, Banarasi organza, raw silk zardozi lehengas) with contemporary fluid silhouettes and world-class digital atelier experiences.

---

## 🌟 Highlights & Features

- **Haute Couture Aesthetic & Custom Color Palette**:
  - Silk Cream (`#F6F7EE`)
  - Celadon Sage (`#D1DDC2`)
  - Eucalyptus Green (`#98B195`)
  - Forest Moss (`#5E715F`)
  - Obsidian Forest (`#1E291F`)
  - Cormorant Garamond serif typography paired with Plus Jakarta Sans.
- **Edge-to-Edge Fluid Runway Architecture**: Full `100vw` layout with streaming scroll entrance reveals.
- **Patron Gateway & Authentication**:
  - High-fashion editorial split authentication view with tabs for **Sign In** and **Create Account**.
  - 1-Click Instant VIP Patron Access (`Priyadharshini Raman`) for testing.
  - Dedicated **Patron Welcome Perks Modal** displaying 10% welcome privilege, master tailoring consultations, insured express delivery, and VIP trunk show pre-access.
- **Header Patron Profile Integration**:
  - Real-time monogram avatar badge (`PR`) with gold rim and online status indicator.
  - Interactive Patron dropdown menu for order tracking, wishlist pieces, and atelier sign-out.
- **Dedicated Full-Page Checkout & Payment**:
  - Multi-option secure payment gateway (UPI QR Code with GPay/PhonePe/Paytm, Cards, Net Banking, COD).
  - Grand celebratory confetti reveal upon order confirmation with refined luxury action buttons.
- **Bespoke Commercial Quotation Included**: Full architectural proposal and freelancer quotation in `Mila_Fashions_Ecommerce_Proposal_and_Quotation.md`.

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite 8
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Celebrations**: Canvas Confetti
- **Styling**: Vanilla CSS Design System with CSS variables

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
